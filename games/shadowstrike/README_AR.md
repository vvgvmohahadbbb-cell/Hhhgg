# Shadow Strike: Last Zone — Offline Battle Royale Prototype

## المحتويات
- 99 بوتًا بالإضافة إلى اللاعب (المجموع النظري 100 شخصية في الجولة).
- عالم ثلاثي الأبعاد مولد برمجيًا: أرض بتفاصيل، مدينة، طرق، أشجار وصخور.
- نماذج مبسطة لشخصيات تكتيكية، سيارات، دبابة، طائرة ودرون (ديكورية وليست قابلة للقيادة/الطيران).
- مؤثرات صوتية مولدة محليًا: إطلاق نار، إصابة، محرك، وتحذير المنطقة.
- نظام صحة، قتلات، إطلاق نار، بوتات تلاحق اللاعب، ومنطقة آمنة تتقلص.
- إعداد GitHub Actions لبناء APK تلقائيًا.

## بناء APK
ارفع جميع محتويات المجلد إلى جذر مستودع GitHub، ثم افتح Actions وشغّل Build Shadow Strike APK. بعد نجاحه نزّل Artifact باسم ShadowStrikeLastZone-APK.

## حدود مهمة
هذه نسخة Prototype قابلة للتطوير، وليست لعبة تجارية مكتملة أو بمستوى PUBG. الشخصيات والمركبات والطائرة والدرون نماذج هندسية مبسطة للعرض فقط؛ ليست أنظمة قيادة أو طيران أو قتال مركبات. البوتات AI بسيط، ولا يوجد لاعبون حقيقيون أو اتصال شبكي. لم يتم اختبار المشروع في محرر Godot أو على جهاز Android هنا؛ قد يحتاج تصحيحًا بعد أول بناء. الحجم مضغوط ومقصود أن يبقى أقل من 100MB؛ جودة اللعبة لا تقاس بحجم الملف وحده.


## تحسينات هذه الحزمة
- إضافة زر قفز وزر إعادة تشغيل من واجهة الهاتف.
- إيقاف الجولة عند نفاد الصحة أو القضاء على جميع الخصوم.
- إزالة الخصم من قائمة الأحياء عند القضاء عليه لتحديث العدادات.
- تحديث GitHub Actions لتثبيت Android SDK قبل محاولة تصدير APK.

## حدود النسخة الحالية
هذه ما تزال نسخة أولية قابلة للتطوير: الشخصيات والبيئة مبنية بأشكال هندسية بسيطة، والمركبات ليست قابلة للقيادة، ولا يوجد نظام هبوط مظلي أو شبكات لعب جماعي أو رسوميات بمستوى ألعاب تجارية. لم يتم التحقق من نجاح التصدير على جهاز فعلي في هذه الحزمة؛ يجب مراجعة سجل GitHub Actions وإصلاح أي خطأ يظهر قبل اعتبار APK جاهزًا.

## تحسينات واجهة النسخة المطوّرة
- واجهة HUD بألوان عالية التباين ولوحات شبه شفافة.
- مؤشر تصويب في منتصف الشاشة.
- عداد ذخيرة وذخيرة احتياطية، وإعادة تلقيم لمدة قصيرة.
- أزرار موبايل أوضح للنار والقفز وإعادة التلقيم وإعادة الجولة.

مهم: هذه تحسينات أولية على النموذج، ولم يتم التحقق من تشغيلها في محرر Godot على جهاز Android بعد. قد تحتاج الواجهة إلى ضبط حسب دقة الشاشة، ويجب اختبار المشروع قبل اعتباره جاهزًا للنشر.
